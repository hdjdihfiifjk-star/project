# انتقال‌یار — Local Wi-Fi / QR

نسخه اصلاح‌شده پروژه انتقال‌یار.

## عملکرد

- گوشی اول APK را نصب می‌کند.
- گوشی دوم هیچ برنامه‌ای نصب نمی‌کند.
- دو گوشی باید روی یک شبکه Wi-Fi محلی باشند.
- گوشی اول یک QR Code نمایش می‌دهد.
- گوشی دوم QR را اسکن می‌کند.
- مرورگر گوشی دوم صفحه وب را از خود گوشی اول دریافت می‌کند.
- فایل‌ها مستقیماً روی شبکه محلی منتقل می‌شوند.
- برای انتقال فایل اینترنت یا سرور ابری لازم نیست.

## رفع خطای web missing

فایل وب در مسیر زیر قرار دارد:

`app/src/main/assets/web/index.html`

و برنامه با `getAssets().open("web/index.html")` آن را از APK می‌خواند.

## ساخت APK با GitHub

1. کل فایل‌های این پروژه را در Repository قرار دهید.
2. وارد تب `Actions` شوید.
3. Workflow با نام `Build Android APK` را باز کنید.
4. `Run workflow` را بزنید.
5. بعد از سبز شدن عملیات، وارد همان اجرای موفق شوید.
6. از قسمت `Artifacts` فایل `EnteghalYar-localwifi-apk` را دریافت کنید.
